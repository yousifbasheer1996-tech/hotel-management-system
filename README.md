# Hotel Management System

A web-based system for booking hotel rooms. Guests can register, log in,
view rooms, book, and pay by credit card or cash. The admin manages rooms
and bookings.

## Process
Agile (Scrum): 4 two-week Sprints. See Issues, Milestones, and the Project board.

## Repository structure
- hotel_system_db.sql: MySQL database script (5 tables)
- main: stable releases
- develop: integration branch
- feature/*: one branch per feature

## Database
MySQL 8.0. Run hotel_system_db.sql in MySQL Workbench.
